Hola Caro! Ya dejé implementada la tarea 4.10 (consultas propias) y la subí en el PR #13.
No tenés que escribir código; tu parte es verificarla y, si querés, aprobar el PR.

Qué se agregó:
- GET /api/orders: lista tus órdenes.
- GET /api/orders/tickets: lista tus entradas.
- GET /api/orders/tickets/{id}: detalle de una entrada tuya.
- Si la entrada es de otro cliente, responde 403.
- Si page o size están mal, responde 400.

Para probarlo (5 minutos):
1) git switch main
2) git pull origin main
3) docker compose -f docker-compose.dev.yml up -d
4) En cuatro terminales:
   cd catalog-service && mvn spring-boot:run
   cd inventory-service && mvn spring-boot:run
   cd orders-service && mvn spring-boot:run
   cd api-gateway && mvn spring-boot:run

Y después:
CLIENTE=33333333-3333-4333-8333-333333333333

curl "http://localhost:8080/api/orders?page=0&size=5" -H "X-User-Id: $CLIENTE" -H "X-User-Role: CLIENT"

curl "http://localhost:8080/api/orders/tickets?page=0&size=5" -H "X-User-Id: $CLIENTE" -H "X-User-Role: CLIENT"

Tenés que ver un 200 con content, page, size, totalElements y totalPages, y solo datos de ese cliente.

Si podés, mandame la salida de los dos curl o pegala en el PR #13. Cualquier error, pasámelo y lo vemos.
Gracias!
